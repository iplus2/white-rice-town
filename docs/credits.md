# 素材来源与署名

- **游戏场景**　小镇建筑、植被、天空、水面、饭碗、地图与音效均为本项目程序生成。工程保留天空生成器及其烘焙结果。
- **鲸鱼娘**　角色原型「溟月」来自上善无形，DeepSeek 女仆造型来自 ZipZipPipe。本项目据参考重新制作了三维模型、绘制材质和动作。角色衍生模型依照 [CC BY-NC-SA 4.0](https://creativecommons.org/licenses/by-nc-sa/4.0/) 共享。
- **参考图片**　两张 JPEG 由项目发起人提供，分别用于造型和表情对照，原图字节保存在 [references](../references/) 中。参考图片的作者信息以原作者标注为准；本项目对衍生模型的授权仅适用于模型。
- **渲染引擎**　Three.js 0.180.0 采用 MIT 许可，声明随成品内嵌，并保存在 [第三方声明](../THREE-LICENSE.txt)。
